பழைய செயலியில் (v1.1.1) புகைப்படம், சுயவிவரம், பதிவுகள் இனி சேமிக்கப்படாது. உங்கள் உறுப்பினர் எண் மற்றும் விவரங்கள் பாதுகாப்பாக உள்ளன.

நிறுவும் முறை

  1. மேலே உள்ள பதிவிறக்கு பொத்தானை அழுத்தி, பதிவிறக்கம் முடிந்ததும் கோப்பைத் திறக்கவும்.
  2. "Install unknown apps" அனுமதி கேட்டால் → Allow from this source இயக்கி, பின் திரும்பவும்.
  3. Install அழுத்தவும். Play Protect எச்சரிக்கை வந்தால் → More details → Install anyway.
  4. செயலியைத் திறந்து, அதே உறுப்பினர் எண் (HSR-…) அல்லது கைபேசி எண் மற்றும் அதே கடவுச்சொல் கொண்டு உள்நுழையவும்.
  5. உள்நுழைந்த பின், பழைய செயலியை நீக்கவும் (சுயவிவரம் → கீழே "செயலி பதிப்பு" v1.1.1 காட்டும் செயலி).

How to install

  1. Tap Download above and open the file when it finishes.
  2. If asked about "Install unknown apps", turn on Allow from this source and go back.
  3. Tap Install. If Play Protect warns you, tap More details → Install anyway.
  4. Open the app and log in with your same member ID / phone and password.
  5. Then uninstall the old app (the one showing v1.1.1 at the bottom of Profile).

When the app is available on Google Play, uninstall this copy once and install it from Play. Your account is not affected. Forgot your password? Contact the party office.
