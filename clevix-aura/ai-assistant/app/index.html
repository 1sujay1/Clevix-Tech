Install in a minute

  1. Tap Download for Android above and open the downloaded file.
  2. If Android asks, allow Install unknown apps for your browser, then tap Install.
  3. Open CLEVIX AURA, tap Sign in with Google, and read and accept the privacy notice.
  4. Allow the microphone, then turn on Screen control (Accessibility → CLEVIX AURA) and notification access from the checklist.
  5. Say “Hey Clevix”, wait for the chime, and ask.

Early access: this download is the first public build ahead of the Google Play launch. When CLEVIX AURA arrives on Google Play, install it from there to get automatic updates.
